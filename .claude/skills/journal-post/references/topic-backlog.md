# Editorial topic backlog

A standing pipeline of Journal post ideas, organised by season and
category. Use this when the `/new-journal-post` skill fires without
a topic argument.

**How to use this file**:

1. Pick the highest-priority entry whose season matches the current month.
2. Skip anything already covered — check existing `_posts/` titles before drafting.
3. After publishing, **strike through** or **delete** the entry from this file so it isn't picked again.
4. Add new entries at the top of each section as topics come up.

Priority key: **P1** publish next, **P2** publish soon, **P3** evergreen / backfill.

## Reactive / event-driven (publish within a week of the trigger)

These don't sit on a schedule — write them when the trigger fires.

- Bank of Canada rate decision (eight times a year).
- TRREB monthly market report (first week of each month).
- New CMHC, OREA, or Ontario Ministry of Housing policy.
- Federal or provincial budget changes affecting housing.
- A material local event: King Township council decisions on lot
  severance, agricultural reserve adjustments, GO transit changes.
